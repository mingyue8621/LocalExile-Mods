# 头顶称号（playertitle）使用说明

在自己头顶显示称号，24 款可选，位置、大小、透明度都能调。装成一个普通模组：启动器的模组页里能看到、能开关、能改设置。

---

## 一、它是什么，为什么这么做

先说清楚一件事：**原版客户端画不出自定义文字**。

- `Content.ggpk` 里没有「文字广告牌」这种资产（查过全部 22044 个 `.ao/.dds` 路径，公告板类的只有任务感叹号那几个），也没有能把任意图片当贴图挂到角色头上的入口。
- ggpk 是 Oodle 压缩的 71.7 GB 单文件，客户端只有读的能力，没有写回的工具链。

所以这个模组走的是**本地透明覆盖层**：一个置顶、点击穿透、不进 Alt+Tab 的透明窗口，把称号序列帧画在角色头顶的位置。它不写客户端文件、不注入客户端进程、不读游戏内存，**只有开这个服务端的那台电脑自己看得见**，别的玩家看不到。

模组本身不做绘制，它负责**托管**：服务端加载模组时把 `overlay/TitleOverlay.exe` 拉起来，卸载时（改设置、`/mod_reload`、`/mod_disable`、关服务端）把它关掉。所以你不需要单独去双击 exe，也不用担心关游戏后台还挂着。

---

## 二、怎么用

### 1. 起服务端

正常用启动器（Waypoint）或 `流放之路服务端.exe` 起服务端。模组加载后，覆盖层自动启动，日志里会有：

```
[mods] playertitle: 头顶称号「九州大侠」已启动（覆盖层 pid 12345）
```

这时还没进游戏，覆盖层是隐藏的（找不到游戏窗口）。**进了游戏、游戏在前台，称号自己就出来了。**

### 2. 选称号、调位置

打开启动器 → **模组** → 找到「**头顶称号**」→ 设置，里面能改：

| 设置 | 说明 |
| --- | --- |
| 显示称号 | 关掉就收起，服务端不用重启 |
| 称号 | 24 款下拉选一个 |
| 自定义称号目录名 | 填了就用它，忽略下拉（给以后新做的素材用） |
| 大小 | 1 = 素材原始像素（220×100 上下） |
| 左右微调 | 相对画面正中左右平移的像素，正数往右 |
| 上下微调 | 称号底边相对画面中心的像素，负数是往上。默认 −100 |
| 不透明度 | 100 不透明；调低更淡，不挡画面 |
| 每帧毫秒 | 播放速度，40 是素材本来的速度 |
| 只在游戏在前台时显示 | 切出去自动收起，不浮在浏览器上 |

改完立刻生效（模组会重载，覆盖层重启一次，闪一下正常）。

### 3. 游戏里的命令

```
/title            列出 24 款可选称号
/title 九州大侠    换成这个
/title sfx_19911  用目录名换也行
/title off        收起
/title on         打开
```

### 4. 热键（不用切出游戏）

全部是 `Ctrl + Alt + 键`：

| 热键 | 作用 |
| --- | --- |
| ↑ / ↓ / ← / → | 上下左右挪 5 像素（按住 Shift 一次 20 像素） |
| `+` / `-` | 放大 / 缩小 |
| `[` / `]` | 上一款 / 下一款称号 |
| `H` | 显示 / 隐藏 |
| `S` | 打开覆盖层自己的设置窗口 |
| `0` | 位置复位（回到画面正中上方 100 像素） |

用热键调好的位置会**保留**：模组只在启动器里改了设置时才重写配置，热键的微调不会被冲掉。

---

## 三、位置是怎么定的

POE 的镜头把**角色脚底钉在画面正中**，所以头顶自然落在中心上方约 100 像素。默认值就按这个：

- 横向：游戏画面正中
- 纵向：称号**底边** = 画面中心往上 100 像素

锚的是「画面中心」而不是绝对坐标，换分辨率不用改。滚轮拉近拉远视角后角色会变大变小，头顶高度跟着变，重新微调一次即可。

---

## 四、前提与限制

1. **游戏必须是窗口化或无边框窗口。** 独占全屏下 Windows 不允许任何置顶窗口画上去，这是系统限制，绕不过。
2. **服务端要和游戏在同一台电脑上。** 覆盖层是服务端拉起的，在服务器的桌面上画；如果服务端在云服务器上跑，你这边看不到（模组日志会说明「不在交互式桌面」）。
3. **只有自己可见。** 这是覆盖层的天然属性，不是给其他玩家看的头顶称号。
4. 服务端以 Windows 服务（会话 0）方式运行时覆盖层起不来，日志会写明；用启动器或控制台在桌面上起就正常。

## 五、文件都在哪

```
Mods/Binaries/playertitle/
  mod.json          模组清单（启动器读它）
  settings.json     设置项声明（启动器据此画表单）
  playertitle.dll   模组本体
  overlay/
    TitleOverlay.exe      透明覆盖层
    titles/sfx_19901..19924/   24 套称号，每套 30 帧 PNG
```

你可能要看的两个位置：

- **覆盖层自己的配置文件**：`data/mods/playertitle/overlay.json`（模组写的，热键微调也存在这里）
- **覆盖层日志**：`Mods/Binaries/playertitle/overlay/error.log`（热键被占用、找不到素材之类会写在这）

## 六、加新称号

把新的序列帧按同样规则放进 `overlay/titles/<目录名>/`（`*.png`，按文件名排序播放），然后：

- 想临时用：启动器里设置「自定义称号目录名」填 `<目录名>`；
- 想进下拉列表：告诉我名字，我把 `settings.json` 的选项和模组里的中文名表一起加上。

素材规格：220×100 上下、30 帧、40ms 一帧的 PNG 序列帧（透明背景）。

---

## 七、排查

| 现象 | 原因 / 处理 |
| --- | --- |
| 进游戏看不到称号 | 先确认游戏是窗口化；再看是否是独占全屏 |
| 切出去称号就没了 | 正常，「只在游戏在前台时显示」开着 |
| 位置偏上/偏下 | `Ctrl+Alt+↑/↓` 调，或启动器里改「上下微调」 |
| 称号太大/太小 | `Ctrl+Alt +/-`，或改「大小」 |
| 名字叠在角色身上 | 把「上下微调」再往上调（更负） |
| `/title` 没反应 | 服务端 `[mods] playertitle` 是否加载成功，看服务端日志 |
| 日志里「不在交互式桌面」 | 服务端跑在会话 0（Windows 服务），改在桌面上起 |

---

## 八、也可以单独跑

不装模组、只想看看效果，可以直接双击 `overlay/TitleOverlay.exe`：会弹设置窗口，功能一样，只是不随服务端自动开关。

命令行参数（模组就是这么调它的，一般用不到）：

```
TitleOverlay.exe --config <json路径> --parent <pid> --silent
```

- `--config`：用指定的配置文件，不写就用 exe 目录下的 `titleoverlay.json`
- `--parent`：看住这个进程，它退出时覆盖层跟着退出（避免服务端崩了留下孤儿窗口）
- `--silent`：不弹设置窗口（热键 `Ctrl+Alt+S` 仍可打开）
