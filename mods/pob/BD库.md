# POB 模组 · 全职业 BD 库

腾讯《流放之路》英雄榜 S29 赛季，每个职业排名最高且详情还在的一份 BD，已抓成 PoB 分享码放进 `data/pob-import/inbox/`。

## 怎么用

```
启动服务端 → 进角色 → 聊天框输入：
  /pob file <文件名>       例如 /pob file Witch.txt
依次按 Y 确认 → 角色自动登出 → 重新进入角色
```

**导入会替换**这个角色的职业、等级、天赋树；**装备、宝石、药水、珠宝不动**；升华点、精通（Mastery）、星团珠宝节点不导入（详见每份的提示）。
