# 通货堆叠（currencystack）

把每一种可堆叠通货的上限提到 **9999**，改数值只改这里的配置，不用再动服务端数据。

## 配置

`settings.json` 两个设置（游戏里也可以用启动器的模组设置改）：

| 设置 | 默认 | 说明 |
|---|---|---|
| `stackSize` | `9999` | 每一种可堆叠通货的上限。范围 2–9999 |
| `overrides` | `{}` | 按通货名单独指定，优先于 `stackSize`，例如 `{ "Chaos Orb": 5000 }` |

用户自己的值写在 `data\mods\currencystack.json`，改完模组会自己重载并生效，不用重启服务端。

## 默认不动的东西

- **满堆自动合成的通货**（混沌裂片 20 → 混沌石 这一类，共 28 种）：把它们的上限抬上去，
  合成阈值会一起被抬高，裂片就再也合不出东西了。要改就在 `overrides` 里写明名字。
- **本身就不可堆叠的通货**（上限本来是 1）。
- **原本就比 9999 更高的**（金币 50000、盗贼印记 25000）：不降低。

## 单项覆盖怎么写

```json
{
  "overrides": {
    "Chaos Orb": 5000,
    "Mirror of Kalandra": 10,
    "Chaos Shard": 200
  }
}
```

`overrides` 里写了的通货**不再受上面三条限制**，写多少就是多少（2–9999）。

## 记录文件

模组在 `data\mods\currencystack.baseline.json` 里记着每种通货「原本的上限」和「现在设成了多少」，
用来判断要不要改、以及改回小数值时按什么基准。删掉它会按当前数据重新记一遍。

## 开启

模组默认是开的。关掉用 `/mod_disable currencystack`，重新打开用 `/mod_enable currencystack`。
