# 通货堆叠（currencystack）

每一种可堆叠通货都有**自己单独的设置项**，直接按名字找到它改上限就行，不用再改服务端数据。

## 怎么改

在启动器：`模组 → 我的模组 → 通货堆叠 → 设置`，往下翻到通货名字，改它右边的数字，点「保存设置」。

- 大多数通货默认是 **9999**
- 改完**立刻生效**，不用重启服务端
- 想恢复某一种，点「恢复默认值」；想全部恢复，点底部的「恢复默认值」

628 种通货都在列表里，按名字排序（Chaos Orb、Exalted Orb、Divine Orb……）。

## 两类默认值不是 9999

- **混沌裂片这类满堆自动合成的**（20 种左右）：默认值保留原来的 20 等数值，设置下有说明。
  把它们抬到 9999 会同时把合成阈值抬到 9999，裂片就再也合不出混沌石了。想改的话自己承担这个后果。
- **原本上限就高于 9999 的**（如某些 50000 的通货）：保留原值，不降低。

## 没有列出来的东西

- 本来就不能堆叠的通货（上限 1）：没有意义，不列。
- 命运卡、地图碎片等别的类别：它们有各自的满堆转换语义，这个模组只管通货类。

## 用户配置在哪

改过的值写在 `data\mods\currencystack.json`，只保存你改过的那些；没改的都用模组自带的默认值。

## 开启 / 关闭

模组默认开启。关闭：`/mod_disable currencystack`；重新打开：`/mod_enable currencystack`。
