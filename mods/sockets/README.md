# 孔位控制

手动决定**击杀掉落**的装备有几个孔、能几连。孔数和几连都可以设成「区间随机」或「固定值」，
还能选只保底、只封顶，以及孔的颜色。

默认关闭：游戏里 `/mod_enable sockets`，或启动器的模组页面打开。**启用后立即按下面的设置生效**，
不需要重启服务端；改设置文件也会即时重载。

## 设置项

| 设置项 | 默认值 | 说明 |
|---|---|---|
| `mode`（改动方式） | `replace`（重排） | `replace`：每件都在「掉落孔数」区间里重新随机；`raise`：只有低于下限才抬到下限；`cap`：只有高于上限才压低；`links`：孔数和孔色都不动，只重排连接 |
| `sockets`（掉落孔数） | `[1, 6]` | 孔数区间。**两端填一样就是固定孔数**：`[6, 6]` 每件 6 孔，`[4, 4]` 每件 4 孔 |
| `linkMode`（连接方式） | `range`（按区间随机） | `range`：用下面的「几连」；`retail`：游戏原本的概率；`full`：全连成一组；`none`：全部断开 |
| `links`（几连） | `[1, 6]` | 连接里**最大一组**的孔数区间。填 `[4, 4]` 就保证每件有一组 4 个孔连在一起 |
| `rarities`（生效稀有度） | 四种全选 | 普通、魔法、稀有、传奇；一个都不勾表示所有稀有度都改 |
| `colours`（孔的颜色） | `attribute`（按属性） | `white`：每个孔都是白色，任何颜色的宝石都能插；`attribute`：按力量/敏捷/智慧需求随机红绿蓝，和游戏原本一致 |

### 几个例子

| 想要的效果 | 设置 |
|---|---|
| 每件都是 6 孔 6 连 | `sockets` = `[6, 6]`，`linkMode` = `full`（或 `links` = `[6, 6]`） |
| 1~6 孔随机、连接也随机 | `sockets` = `[1, 6]`，`linkMode` = `range`，`links` = `[1, 6]` |
| 至少 4 孔 4 连，原本更好的保留 | `mode` = `raise`，`sockets` = `[4, 4]`，`links` = `[4, 4]` |
| 最多 3 孔，压掉过强的掉落 | `mode` = `cap`，`sockets` = `[1, 3]` |
| 只让传奇必出 6 孔 | `rarities` 只勾「传奇」，`sockets` = `[6, 6]` |
| 孔数完全不动，只把掉落连成 6 连 | `mode` = `links`，`linkMode` = `full` |

`raise` 和 `cap` 模式下，孔数没有越过下限/上限的装备**整件不动**，连接也保持游戏原本的样子。

## 不会被改动的装备

这些底子的孔数由物品本身定，改了会让客户端显示错乱或吞掉宝石：

| 情况 | 原因 |
|---|---|
| 腰带、项链、戒指、珠宝 | 没有 Sockets 组件，本来就没有孔 |
| 共鸣器（Resonator） | 孔数由物品固定 |
| 深渊腰带（Stygian Vise） | 固定 1 个深渊孔 |
| 自带单孔的底子（`local_has_X_sockets` 固定为 1） | 孔数写在基底词缀里 |
| 孔里已经有宝石的装备 | 重建孔会把宝石弄丢 |

## 上限

孔数受装备类型和尺寸限制，设再高也会被压到实际能放的孔数：

- **1 格宽的长杖之类（1x4）最多 3 孔**：客户端按列摆孔，每列最多 3 个、最多 2 列
- **单手武器、盾牌最多 3 孔**
- **双手武器、胸甲、手套、鞋子、头盔最多 6 孔**

「几连」超过实际孔数时按孔数算：3 孔设 6 连，结果就是 3 连。

## 生效范围

只作用于**击杀掉落**的装备。商店、任务奖励、赌博、保险箱、工艺台走的是各自的路径，不受影响。
