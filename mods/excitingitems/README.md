# 惊喜物品（Exciting Items）

魔法、稀有、传奇掉落各有小概率带上下面的效果，三种概率独立，而且**可以同时落在同一件物品上**：

- **传奇固定词缀。** 物品额外获得 1~3 条传奇物品的词缀，当作固定词缀。越稀有的传奇，它的词缀出现得越少
  （与那件传奇自身的掉落率一致）。
- **强化词缀。** 物品自带的某一条词缀（固定或明文，含上面加的传奇固定词缀）数值超出上限地滚一次：
  原值乘以 1.1 到 2（在设置给的区间里随机），突破该词缀所在阶的上限。带负面效果、或「没有插槽」这类开关型词缀
  永远不会被选中。
- **额外破碎词缀。** 物品比它本该有的多一条词缀：稀有物品填满 3 前缀 + 3 后缀后再多一条（变成 7 条，稀有珠宝 5 条），
  魔法物品 3 条，传奇物品则按稀有的规则多一条前缀或后缀。这一侧（前缀或后缀）的每条词缀都会被破碎
  （传奇只破碎新加的那条）。这些词缀也可以是只有势力物品才会出现的词缀（随机取一个该物品本身没有的势力，
  按它的物等允许的阶取），而物品本身不会变成势力物品。

这些效果对势力物品同样生效：游戏里「不能破碎势力/合成物品」的规则是针对通货的，不针对掉落。带任一效果的物品
会以**合成**外观掉落，在地上看起来很特别；开着 `showInFilters` 时，模组会往你过滤器顶部加一条规则，让它带光柱和
音效。聊天里只说掉到了哪种效果，不说具体是什么——鉴定出来才知道。

## 哪些传奇词缀可以出现

由 `implicits.mode` 选一种：

| 模式 | 能出什么 |
|---|---|
| 狂野（默认） | 任何装备出任何传奇词缀 |
| 合理 | 只出同类物品对应传奇的词缀：剑的出剑的，腰带的出腰带的 |
| 主题 | 武器、箭袋、手套出攻击；胸甲、盾牌出防御；鞋子出移速与异常状态；头盔出防御与成长类（每球、每属性、光环、召唤物）；戒指、项链、腰带出功能性与各种稀奇古怪的传奇效果 |

任何模式下，词缀出现在它自己那类物品上都是允许的（头盔传奇的词缀可以上头盔），而所有没被拉黑的词缀
都能在某处出现：被选中模式没给位置的，按「狂野」的规则走；属于永远不会掉落的那类物品的（比如鱼竿），
可以上任何装备。稀有与魔法珠宝在任何模式下都只拿传奇珠宝的词缀，装备永远拿不到这些。词缀里点名了某类物品、
或只对那类物品生效的（加物品自身护甲、插槽相关），会留在那类物品上。集群珠宝与永恒珠宝什么都拿不到。

`blacklist` 列出永不使用的词缀：Mods 的 id 或它的开头、`stat:` 加一段 stat id、或 `class:` 加物品类别
（该类物品的传奇词缀留在它自己身上）。默认值是那些与自身物品绑死的词缀：范围珠宝与永恒珠宝的天赋树特效、
希望之线的环、按序号赋予的辅助（禁断的萨科）、只有那件传奇才有的效果（`local_unique_` 类 stat）、
无尽之衣与等级需求类词缀，以及药剂、酊剂、地图、神像、圣所遗物的词缀（`class:`）。除此之外的任何传奇词缀，
在任何模式下都能出现在某类装备上。

## 命令

| 命令 | 作用 |
|---|---|
| `/exciting` | 查看当前概率与模式 |
| `/exciting next implicit [1-3]` | 下一件魔法、稀有或传奇掉落获得指定条数的传奇固定词缀 |
| `/exciting next empowered` | 下一件获得一条强化词缀 |
| `/exciting next extra` | 下一件获得一条额外破碎词缀 |
| `/exciting next all` | 下一件三种效果全给 |

## 设置

| 设置 | 默认 | 作用 |
|---|---|---|
| `implicits.chance`、`chanceTwo`、`chanceThree` | 1000、100000、1000000 | 获得 1/2/3 条传奇固定词缀：1 / N 次掉落 |
| `implicits.mode` | 狂野 | 狂野、合理或主题（见上） |
| `implicits.rarityWeights` | 开 | 越稀有的传奇，词缀出现得越少 |
| `implicits.rarities`、`empowered.rarities`、`extraModifier.rarities` | 魔法、稀有、传奇 | 哪些品质的掉落能获得对应效果 |
| `empowered.chance` | 500 | 1 / N 次掉落 |
| `empowered.percent` | 10-100 | 强化幅度，在区间内随机 |
| `extraModifier.chance` | 1000 | 1 / N 次掉落 |
| `extraModifier.influencedMods` | 开 | 额外词缀也可以是势力词缀（物品本身不会变成势力物品） |
| `blacklist` | （见上） | 绝不作为固定词缀的词缀 |
| `mark`、`showInFilters` | 开、关 | 合成外观，以及过滤器光柱规则 |
| `announce` | 开 | 聊天提示 |
| `filterFolder` | （空） | 过滤器目录；留空为 Documents\My Games\Path of Exile\LocalExile |

开着 `showInFilters` 时，过滤器规则会写在目录里每份 `.filter` 文件顶部的两行标记之间，关掉设置就会撤出。
你自己没有过滤器时，模组会写一份只含这条规则的过滤器。

**只改新掉落**：玩家从背包里扔到地上的物品不会被重新掷骰。

适用于 LocalExile 0.6.0-beta（1.0.2 版本）；更早的 1.0.1 适用于 0.5.2-beta。
