# 地图掉落

控制每次击杀掉多少地图，做法和控制通货的那个模组一样。

服务端本来自己会滚一次地图掉落，但这个端的每个地图区域刷出来的怪比正式服少得多，
只靠那一次滚动，玩家经常打到没图可打。这个模组额外滚一次：按怪物稀有度给概率，
掉落与当前地图同阶（地图外按固定阶数），地图首领必掉一张。

默认启用。`/mod_disable mapdrop` 可以关掉，`/mod_settings mapdrop` 看当前设置。

## 设置

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 普通怪掉图率 | 0.03 | 普通怪物每次击杀掉一张地图的概率，0.03 就是百分之三 |
| 魔法怪掉图率 | 0.07 | 魔法（蓝色）怪物 |
| 稀有怪掉图率 | 0.15 | 稀有（黄色）怪物 |
| 传奇怪掉图率 | 1 | 传奇怪物，包括地图首领 |
| 跟随当前地图阶数 | 开 | 掉的地图与击杀所在的地图同阶 |
| 地图外的掉落阶数 | 1 | 剧情、藏身处，以及关闭上面那项时的阶数 |
| 第一章到第五章也掉图 | **关** | 关着和正式服一致：A6 之后和地图里才掉 |
| 掉更高阶的几率 | 0.2 | 每次掉地图有 20% 概率往上提阶 |
| 一次提高几阶 | 1 | 触发提升时提多少阶 |
| 最高阶数 | 16 | 提升后的上限 |
| 仅限这些怪物 | 空 | 留空表示全部；否则种类 id 或名字要包含其中一项 |

这些是每只怪的额外概率，叠加在服务端自己那次地图滚动之上。

## 从哪里开始掉

正式服里地图是**第六章才开始掉**的，所以这个模组也一样：只有 A6 到 A10 的区域、以及异界地图里击杀才会掉图。
A1 到 A5、藏身处、矿坑都不掉。

判断依据是区域 id：`2_` 开头是第二部曲（A6 到 A10），`MapWorlds*` 是异界地图。

想在第一章就掉图，把「第一章到第五章也掉图」打开即可，掉落阶数按「地图外的掉落阶数」走。

## 为什么会掉出更高阶的地图

正式服里地图掉落跟着区域阶数走，往更高的方向靠 Atlas 完成度和「地图阶数 +1」那类加成。
这个服没有 Atlas 进度，所以给了模组自己一次提升：每次掉图先按上面的概率掷一次，
中了就把阶数往上提几阶（不超过最高阶数）。默认 20% 提 1 阶，
所以在 T1 图里刷图，大约每五张里有一张是 T2 及以上的。
