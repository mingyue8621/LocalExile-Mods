# 地图掉落

控制每次击杀掉多少地图，做法和控制通货的那个模组一样。

服务端本来自己会滚一次地图掉落，但这个端的每个地图区域刷出来的怪比正式服少得多，
只靠那一次滚动，玩家经常打到没图可打。这个模组额外滚一次：按怪物稀有度给概率，
阶数照官方的算法（剧情只掉 T1，地图里普通同阶、魔法稀有 +1、首领 +2），首领必掉一张。

默认启用。`/mod_disable mapdrop` 可以关掉，`/mod_settings mapdrop` 看当前设置。

## 设置

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 普通怪掉图率 | 0.03 | 普通怪物每次击杀掉一张地图的概率，0.03 就是百分之三 |
| 魔法怪掉图率 | 0.07 | 魔法（蓝色）怪物 |
| 稀有怪掉图率 | 0.15 | 稀有（黄色）怪物 |
| 传奇怪掉图率 | 1 | 传奇怪物，包括地图首领 |
| 跟随当前地图阶数 | 开 | 掉的地图与击杀所在的地图同阶 |
| 剧情里掉的阶数 | 1 | 官方剧情只掉 T1；关闭上面那项时地图里也用这个 |
| 所有章节都掉图 | **关** | 关着和官方一致：A8 之后和地图里才掉 |
| 最高阶数 | 16 | +1、+2 之后的上限 |
| 仅限这些怪物 | 空 | 留空表示全部；否则种类 id 或名字要包含其中一项 |

这些是每只怪的额外概率，叠加在服务端自己那次地图滚动之上。

## 从哪里开始掉

官方 wiki（Maps）原文：地图最早在**第八章**以掉落的形式出现，剧情阶段只会掉最低阶。
所以这个模组也一样：A8 到 A10 的野外和异界地图里才掉，A1 到 A7、藏身处、矿坑都不掉。

判断依据是区域 id：`2_8…`/`2_9…`/`2_10…` 是第二部曲的后三章，`MapWorlds*` 是异界地图。

想从头就掉图，把「所有章节都掉图」打开即可。

## 阶数怎么算

照官方的规则（poewiki，Maps）：

- **剧情（A8 到 A10）**：只掉最低阶，也就是 T1
- **地图里**：普通怪掉本图同阶，**魔法怪和稀有怪掉 +1 阶**，**地图首领掉 +2 阶**
- 上限 T16（官方还有虚空石让所有掉落再 +1 阶，并把低于 T16 的转成金币，这个服没有虚空石）

举例，在 T3 图里：普通怪掉 T3，魔法怪和稀有怪掉 T4，地图首领掉 T5。
